Privacy Policy

Last updated: November 19, 2026

GGames Uploader is a private tool operated by the owner of the GGames Highlights channels. It is used only to upload videos to the owner's own accounts.

Data we access

The tool uses OAuth access granted by the channel owner (for example the YouTube Data API youtube.upload scope) solely to upload videos and set their titles and descriptions.

Data we store or share

Access tokens are stored only on the owner's own computer. No personal data of any other person is collected, stored, sold or shared with third parties.

Google API Services

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. The tool uses YouTube API Services; see the YouTube Terms of Service and the Google Privacy Policy.

TikTok

With TikTok Login Kit the tool reads only the owner's basic profile (user.info.basic: open_id and display name) to confirm the connected account. With the Content Posting API (video.upload, video.publish) it uploads the owner's own clips to his TikTok account. No data of other TikTok users is accessed. TikTok tokens are stored only on the owner's computer. See the TikTok Privacy Policy.

Revoking access

Access can be revoked at any time: Google at myaccount.google.com/permissions; TikTok in the app under Settings and privacy > Security > Apps and services.
